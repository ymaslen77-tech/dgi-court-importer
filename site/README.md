# Единая справочная служба Москвы — перенос Webflow → Next.js

**Первая ветка разработки, не готовый перенос:** действующий Webflow остаётся источником полных юридических материалов. Новый сайт содержит маршруты/SEO-снимок и каркас CMS; прежде чем публиковать, необходимо перенести и редакционно сверить тексты и изображения.

## Стек

Next.js 16.3.3 + TypeScript + Tailwind CSS, Payload CMS 3.90.2, PostgreSQL 17. Исходные Python-импортёры и GitHub Actions остаются в корне репозитория нетронутыми.

## Локальный запуск

1. Установите Node.js 24.15+, pnpm 10, Docker.
2. Скопируйте `.env.example` в `.env`. Задайте **одинаковый пароль** для `POSTGRES_PASSWORD` и пароля в `DATABASE_URL`; создайте случайный сильный `PAYLOAD_SECRET`. Никогда не коммитьте секреты.
3. `docker compose up -d postgres`
4. `pnpm install --no-frozen-lockfile`, затем `pnpm dev`.
5. Сайт: `http://localhost:3000`; редакция: `http://localhost:3000/admin`.
6. Проверки: `pnpm test`, `pnpm typecheck`.
7. Импорт только SEO-черновиков: `pnpm import:pages` (preview) → `pnpm import:pages -- --execute` (создать черновики, **без публикации**).

**Защита от преждевременного запуска:** пока `SITE_PUBLIC_INDEXING=false`, robots запрещает индексацию, страницы возвращают `noindex`, а неперенесённые материалы ведут на Webflow. На staging-сервере дополнительно настройте HTTP Basic Auth или IP allowlist; robots/noindex не ограничивают доступ.

## Фактически реализовано

- Карта 33 публичных URL и SEO-метаданных из Webflow: `src/data/webflow-pages.json` (внутренний архивный макет исключён).
- Публичный каркас главной, каталога судебных карточек и прочих маршрутов; чёрно-красно-белый стиль.
- Payload коллекции `pages`, `news`, `court-cases` и редакционная авторизация. Публичное чтение только верифицированных и опубликованных материалов.
- 16 **непроверенных метаданных** кассационных судебных карточек в демокаталоге, без правовых выводов.
- Редакторская миграция SEO-снимка в черновики; SQL-основа индексируемой таблицы судебных метаданных.
- Python-импортёры и их workflows **не изменены**.

## Не сделано и не заявляется сделанным

Полный экспорт HTML и CMS, фотографии и права на них, верификация судебных актов, импорт новостей, поиск с реальной PostgreSQL БД, тестовый production build/CI, создание lockfile, развёртывание на хостинге, переключение DNS и SEO QA.

Полный план и критерии запуска: `../docs/site-migration.md`.
