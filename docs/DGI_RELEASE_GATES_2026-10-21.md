## Двойная защита поисковой индексации

1. Глобальный production-переключатель остаётся закрытым без специального разрешения и эксплуатационной проверки.
2. `scripts/seo-release-eligibility.mjs` дополнительно требует доказательное `legalSignoff` **для каждой** одобренной единицы, а не просто редакционный Boolean. Даже массовое присвоение `editoriallyApproved=true` либо `publicationApproved=true` не снимает запрет.
3. `legalSignoff` отражает работу человека; программа **не может** самостоятельно подтвердить полноту действующей редакции или наличие всех последующих поправок.

Минимальная запись о проверке для юридически утверждаемого материала:

```json
{
  "legalSignoff": {
    "approved": true,
    "reviewedBy": "ФИО или уникальный идентификатор ответственного редактора",
    "reviewedOn": "YYYY-MM-DD",
    "editionCheckedThrough": "YYYY-MM-DD",
    "officialDocumentUrl": "https://www.mos.ru/upload/.../official.pdf",
    "reasonedFinding": "Развёрнутый результат проверки нормы, применимых изменений и редакции",
    "allMaterialAmendmentsChecked": true,
    "fullTextAndAnnexesChecked": true
  }
}
```

Этот пример **не является выданным допуском**. Заполнять его можно только по реально выполненной документированной юридической проверке; недостаточно ссылки на старый PDF. HTTPS и допустимый официальный домен — лишь технические условия, не правовая оценка.

## Порядок предметной проверки

- **Нормативные акты (20):** идентификация по органу, дате, номеру и приложениям; полный текст, каждая поправка и её дата вступления в силу. Отдельно два постановления № 521-ПП с разными датами (10.09.2014 и 11.03.2026). Проверить, какие приложения № 521-ПП 2014 года изменены № 820-ПП от 25.03.2026, и последующие поправки, если есть.
- **Услуги ДГИ (7):** сопоставить действующий регламент со всеми формами; категория заявителя, способы обращения, документы, сроки, приостановление, отказ и досудебное обжалование. Разграничить полномочия ДГИ, Мосжилинспекции, префектур и других органов.
- **Страницы и инструкции (51):** проверить каждое конкретное юридически значимое утверждение и ссылки на официальные материалы; зафиксировать дату проверки и редактора.
- **Судебная практика:** метаданные не равны полному акту. Не писать результат спора по одному статусу карточки. Проверить официальный полный текст, номер, дату, инстанцию, относимость к ДГИ, соответствие резолютивной части и обезличивание, затем индивидуально допускать в Neon и sitemap.

## Эксплуатационный контроль

`scripts/production-http-smoke.mjs` теперь проверяет **основной пользовательский домен** `https://dgi-pravo.ru`, а не технический Vercel alias. Допустим только HTTPS, пользовательский домен и известное перенаправление на `www` внутри этого домена. При закрытом релизе тест требует `noindex`, закрытый robots и пустой sitemap. Переменная `DGI_PUBLIC_ORIGIN` предназначена только для выбора `dgi-pravo.ru` / `www.dgi-pravo.ru`.

## Решение о завершённости

Техническая исправность импорта, отсутствие ошибок CI и доступность Vercel **не означают**, что действующие редакции всех актов проверены. До полноценной юридической приёмки и подтверждения конечных текстов судебных актов открывать общий поисковый релиз нельзя.
