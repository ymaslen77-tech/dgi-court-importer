# ДГИ — офлайн-разработка и проверка перед выпуском (14.10.2026)

## Режим работы и изоляция

- Рабочая ветка: `feature/dgi-offline-completion`. Ветка `main`, публичный сайт, DNS и опубликованное содержимое не меняются.
- Для этой ветки добавлены `git.deploymentEnabled=false` в конфигурациях корневого и `apps/web` проектов. Вызовов Vercel Deploy или GitHub Release нет.
- CI выполняется в одноразовых процессах GitHub Actions. `Offline production publication guard` проверяет сборку в режиме с установленными `SITE_CUTOVER=true` и `SITE_RELEASE_APPROVED=yes`, с несуществующим тестовым доменом и выключенными публичными чтениями CMS/судебной БД.
- Режим проверки **не** является разрешением на выпуск, публикацией или юридической приёмкой.

## Исправленная техническая защита

1. Статические Webflow-снимки не используются как резервный публичный контент при активном режиме выпуска. Для отображения страниц нужен индивидуально одобренный материал из PostgreSQL.
2. На уровне SEO активна проверка `editoriallyApproved`, на уровне глобальных метаданных по умолчанию `noindex`. Публикуемый sitemap собирается только из допущенной SQL-проекции и исключает судебный каталог-кандидат и архив дел.
3. Неодобренные правовые инструкции и справочник актов доступны для локального ознакомления только до переключения режима выпуска.
4. 22 старые судебные карточки остаются адресуемыми, но `noindex` и без утверждения результатов рассмотрения. Судебный поисковый индекс может работать как **поисковый ориентир**, а не как юридически утверждённый акт.
5. Общая ссылка на список апелляций по делу 02-4422/2026 больше не предлагается как подтверждение именно этого дела. В БД серверный фильтр отклоняет общие страницы поиска по делам. Исходная ссылка остаётся в закрытом реестре на сверку суда и УИД.
6. Next.js больше не читает каталог дел динамически из произвольного пути файловой системы: 16 обезличенных кандидатных записей сохранены как статический, проверяемый снимок. Для большого и обновляемого каталога предусмотрено отдельное чтение из PostgreSQL. Проверка снимка сравнивает его с 16 строками исходного JSONL.

- Браузерные тесты desktop/mobile: [успешный запуск](https://github.com/ymaslen77-tech/dgi-court-importer/actions/runs/38614908376).
- Дополнительный изолированный release-mode smoke: [успешный запуск после исправления тестового ожидания](https://github.com/ymaslen77-tech/dgi-court-importer/actions/runs/38616219362).
- Последние изменения судебного каталога и синхронизации снимка требуют **собственного** завершённого CI на последнем коммите; успешные проверки предыдущих коммитов не означают успех HEAD.

## Юридический статус — не путать с техническими тестами

- 50 записей CMS сверены как исходный инвентарь (37 судебных, 4 нормативных, 6 правовых ситуаций, 3 новости), но **ни одна** не получила автоматического разрешения на юридическую публикацию.
- Для восьми судебных записей ранее установлены официальные карточки по номерам и идентификаторам; это не подтверждение судебных выводов, мотивировки и всех инстанций. Ещё 28 судебных записей не имеют прямой официальной ссылки; одна содержит лишь общий список дел.
- Все 22 исторические судебные карточки остаются без утверждения судебного результата.
- Для четырёх исходных нормативных CMS-записей требуется действующий официальный консолидированный текст, приложения, вступление поправок в силу. В частности, 521-ПП изменено 820-ПП от 25.03.2026 и 1235-ПП от 05.05.2026; справочные сведения и исторические PDF не заменяют официальную правовую проверку. Исследовательская ссылка: https://base.garant.ru/57392261/
- В отдельной жилищной базе 16 актов и 11 инструкций с шестью расширениями сохраняют неподтверждённый статус редакции/процедуры. Сроки, требования, результаты и компетенция органов не могут объявляться окончательно проверенными.

## Условия завершения и выпуска

- [ ] Все актуальные GitHub Actions на HEAD зелёные; нет критичных предупреждений сборки, нарушений публикационных ворот или отсутствующих маршрутов.
- [ ] Проведена покомпонентная визуальная, функциональная, доступностная и юридическая приёмка материалов.
- [ ] Для каждой судебной записи с заявленным результатом есть точный официальный акт и проверена история движения по инстанциям. Непроверенные записи остаются заблокированными.
- [ ] Для нормативных документов получены официальные актуальные редакции с приложениями и проверкой даты вступления поправок в силу.
- [ ] Отдельно подтверждены права на медиа, проверены резервное копирование/восстановление, безопасность хранилищ, права CMS и операционные сценарии.
- [ ] Подписано разрешение редактора, юриста, SEO и ответственного за выпуск. Только затем обсуждать публикацию и перенос домена.

Пока перечисленные юридические и эксплуатационные требования не выполнены, **не переводить PR в Ready, не объединять с main и не запускать релиз**.
