# Новости жилищного права Москвы: редакционный процесс

## Публичные страницы
- Сайт: https://dgimos.webflow.io/
- Новости: https://dgimos.webflow.io/novosti-zhilishchnogo-prava
- CMS-коллекция: `6acbbe75ee81535770a2bff7` — «Новости жилищного права Москвы»

В октябре 2026 подготовлены 3 оригинальных редакционных обзора на публичной странице и 3 записи в CMS в статусе **Draft / editorial_review**. Они намеренно не опубликованы как новые отдельные динамические CMS-страницы: в текущей реализации публичная страница и главный блок наполнены статическим редакционным содержанием. Новые кандидаты, собранные автоматикой, **не появятся на сайте сами** до редакционной проверки и переноса/публикации.

## Источники
1. [ДГИ и город Москва](https://www.mos.ru/dgi/) — собственность, жильё, нормативные услуги. Сейчас редакционный мониторинг; автоматический адаптер отсутствует.
2. [Вестник Москвы](https://vestnikmoscow.mos.ru/) — официальная публикация актов столицы. Ручная сверка действующей редакции.
3. [Верховный Суд](https://www.vsrf.ru/) — официальные акты и судебные позиции, ручная сверка.
4. [pravo.gov.ru](https://www.pravo.gov.ru/) — официальное опубликование нормативных актов, ручная сверка.
5. [КонсультантПлюс](https://www.consultant.ru/law/hotdocs/t3198/) — мониторинг новых документов ЖКХ; первоисточники сверяются отдельно.
6. [ГАРАНТ.РУ](https://www.garant.ru/news/) / RSS: `https://rss.garant.ru/news/` — **первый подключённый технический источник кандидатов**, не право перепечатывать тексты и фотографии.

## Автоматический сбор

Файлы:
- `news_importer.py`: читает RSS-метаданные, извлекает заголовки, даты и ссылки; фильтрует жилищную тематику, проверяет домен, сравнивает URL с текущими CMS-записями, добавляет только черновики.
- `.github/workflows/daily-housing-news.yml`: запускает тесты и поиск ежедневно в 06:15 UTC (09:15 МСК), при успехе создаёт до 15 черновиков в день.
- `tests/test_news_importer.py`: проверки фильтра, ограничения ссылок, стабильной дедупликации и запрета автоматической публикации.

GitHub Actions → workflow `Housing-law news — RSS candidates (draft only)` → `Run workflow`:
- `upload=false` — тест без записи в CMS;
- `upload=true` — создание **только черновиков**, публикации нет.

Используется существующий GitHub Secret `WEBFLOW_TOKEN`. Добавлять его в код или GitHub Variables нельзя.

## Редакторская подготовка оригинального юридического материала
1. Открыть исходную публикацию и идентифицировать первичный документ (акт, решение, законопроект или позицию ведомства).
2. Сверить номер, дату, редакцию, юрисдикцию, действующий статус и дату вступления в силу. Если первичный документ не найден, пометить обзор как непроверенный.
3. Изложить **самостоятельно проверенные факты**, а не делать «глубокий рерайт» полного текста чужой публикации. Ни один длинный фрагмент сторонней статьи не копировать.
4. Объяснить **что произошло → кого касается → какой статус нормы → что проверить/какие документы подготовить**, применительно к жителям Москвы.
5. Добавить ссылку на исходный материал и по возможности прямую ссылку на нормативный акт или судебное решение.
6. Не публиковать ранее редакционной проверки. Не использовать сторонние изображения без лицензии.
7. После проверки установить `provereno-redaktorom=true`, `status-verifikacii=verified`, заполнить содержательные поля и отдельно опубликовать CMS-материал; для отображения в текущем статическом новостном разделе требуется редакционное добавление карточки.

## Ограничения первой версии
- Автоматический генератор полных оригинальных обзоров **не подключён**; он потребует надёжного получения и проверки первоисточника, редакционных требований и отдельной конфигурации AI API, если решено использовать AI.
- Нет автоматической публикации, чтобы не создавать ложные юридические утверждения.
- Проверить успешный первый GitHub Actions run, реальный RSS XML и формат Webflow на живом импорте; текущая разработка прошла проверку кода, но не испытание рабочего RSS на GitHub.
- Статическая публичная страница из трёх вручную подготовленных публикаций; для динамического ежедневного отображения после модерации потребуется подключить CMS Collection List и шаблон отдельной новости в Webflow.
