# Обезличенный судебный каталог — проверка перед публикацией

Обновлено: 20.10.2026. Источник — официальный экспорт `data.mos-gorsud.ru`, разрешённый правилами загрузчика `court_catalog.py`.

## Что запускается еженедельно

`.github/workflows/moscow-housing-court-catalog.yml` загружает официальный архив (ZIP, внутри JSON), читает его потоково и отбирает только **метаданные кандидатов** по жилищным темам: название суда, номер дела, УИД при наличии, категорию, тему и **URL официальной карточки**. Имена участников, адреса, исходы спора, документы сторон и выводы суда не сохраняются.

Вместо автоматического коммита в `main` каждую неделю создаётся **временный артефакт GitHub Actions** `moscow-housing-court-candidates-for-legal-review` (14 дней хранения). Он не виден в публичном Next.js и не записывается в Neon.

## Юридическая приёмка кандидатов

1. Скачайте артефакт из успешного задания GitHub Actions; проверьте метаданные и официальные ссылки.
2. Установите, относится ли дело к жилищному праву, участвует ли ДГИ и есть ли официальный опубликованный мотивированный акт.
3. Проверьте УИД, инстанцию, дату, результат, обжалование, изменения решения; не делайте выводов только по названию категории или участникам.
4. Проверяйте персональные данные перед публичным сохранением. Даже если открытый судебный источник содержит неанонимизированные данные, это не означает разрешение републикации.
5. Импортируйте только утверждённые документы через отдельный проверенный процесс `scripts/import-official-court-act.mjs`, начиная со `staging`. **Не** включайте `courtActApproved` или индексирование без юридического допуска.

## Безопасность и эксплуатация

- Плановый запуск только формирует исследовательский артефакт. Коммит метаданных в Git разрешён **лишь при ручном workflow_dispatch с `write_catalog=true`**.
- Перед каждой записью валидируется точный набор полей и `act_reviewed=false`.
- ZIP не распаковывается по именам файлов из архива на диск; парсер использует строго один JSON-вложенный файл и ограничивает коэффициент распаковки.
- Значение `dry_run=false` в отчёте загрузчика означает **создание локального файла на эфемерном раннере**, не выпуск контента сайта.
- Если загрузка или проверка завершилась ошибкой, не считать полученный набор полным.
- По результатам реального read-only теста 20.10.2026 удалось извлечь 2 500 новых кандидатов из первых 34 639 просмотренных записей, но ни один из них пока не получил юридическую отметку об утверждённом судебном акте.

**Статус:** каталог кандидатов подготовлен технически; юридическая приёмка и импорт полнотекстовых актов не завершены.
