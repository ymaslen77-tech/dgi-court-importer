# DGI Court Importer

Консервативный загрузчик опубликованных судебных актов с участием Департамента городского имущества города Москвы в Webflow CMS.

**Статус:** код импортёра подготовлен. Импорт не включён, пока не заданы `WEBFLOW_TOKEN` и прямой URL JSON-выгрузки `COURT_DATASET_URL`, не проверены условия использования и фактическая схема данных.

## Назначение

- Цель: не менее 1000 **проверенных** судебных актов в базе; пополнение — **до 50 подходящих документов в неделю**.
- Источник кандидатов: официальные открытые данные [судов Москвы](https://data.mos-gorsud.ru/opendata), при условии доступа к законно распространяемой машиночитаемой выгрузке.
- Импортируются **черновики**, а не опубликованные материалы: запись в статистическом наборе ≠ проверенная резолютивная часть судебного акта.
- Никакого обхода CAPTCHA, блокировок, лимитов или сбора персональных данных сверх необходимого.
- Проверка дублей по хешу характеристик акта и URL, в том числе в существующей CMS.
- Не выдаём цель 50/неделю за гарантированный результат: источники и качество данных могут ограничивать выдачу.

## Установка и проверки

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Локальная проверка без записи в CMS:

```bash
python importer.py --input official-courts.json --source-label https://data.mos-gorsud.ru/opendata --limit 50
```

Загрузка **черновиков** (без публикации):

```bash
WEBFLOW_TOKEN=... python importer.py --input official-courts.json --download-url https://data.mos-gorsud.ru/.../actual.json --limit 50 --upload
```

Вместо передачи токена в командной строке используйте переменную окружения или секрет GitHub Actions. Не сохраняйте токен в файлах проекта.

## GitHub Actions

В настройках репозитория **Settings → Secrets and variables → Actions**:

- **Secret** `WEBFLOW_TOKEN`: токен Webflow с разрешениями `cms:read`, `cms:write` к соответствующему сайту.
- **Variable** `COURT_DATASET_URL`: **прямой URL JSON-файла**, доступный без обхода защитных мер; HTML-страница каталога не подходит.

Workflow `.github/workflows/weekly-dgi.yml` запускается по понедельникам в 06:00 UTC (09:00 МСК) и вручную. Пока переменные не установлены, проверка конфигурации безопасно завершится ошибкой без загрузки записей.

Для одноразовой начальной партии можно вручную запустить workflow c `batch_size=1000`, однако это только лимит **черновых кандидатов**, не обещание 1000 проверенных решений.

## Ограничения и план до производства

1. Подтвердить URL и формат именно той официальной JSON-выгрузки, которую будем загружать.
2. Протестировать маппинг полей на реальном образце, а не предполагать совпадение названий.
3. Проверять, что ДГИ действительно является участником дела; различать суд, УИД, инстанцию, номер и ссылки.
4. Проверять сам текст решения, резолютивную часть и историю апелляций — **только после этого** переводить запись из черновика.
5. Разработать постраничный/серверный полнотекстовый поиск для 1000+ документов: клиентский фильтр Webflow по первой сотне карточек не решает эту задачу.
6. При необходимости подключить отдельный БД/поисковый сервис. Webflow остаётся публичным CMS и интерфейсом.
